## 为什么做这个

市面上的刷题工具把英语拆成了孤立的选项，背了忘、忘了背。
本项目反其道而行：**用一部 30 章的连续剧当教材**——主角阿洛从「词力为零」一路升级到「词帝加冕」，所有单词、语法、易混词都长在剧情里。配套完整的题型特训与错题回炉，构成「学 → 练 → 测 → 复」的完整闭环。

## 特性总览

### 章节学习（学）
- **30 章连续剧情**：觉醒篇 → 秘境篇 → 词帝篇，角色宇宙贯穿全程
- **双栏布局**：左边读故事（生词可点击弹释义），右边同步攻知识点，边读边学
- **157 张语法卡**：每张 = 规则 + 剧情例句 + 判定口诀 + 快答，覆盖教师课堂全清单（54 项考点审计 100%）
- **熟词生义暗雷阵**：book / address / figure 这些「你以为你认识」的词，专项拆解
- **视觉小说模式**：一键切换演出态，对话框 + 打字机逐句推进

### 题型特训（练）—— 对标 2026 真实卷面
| 题型 | 分值 | 训练内容 |
|---|---|---|
| 阅读理解 | 40 分 | 四大题型方法 + 真题示范 + 3 套练习 |
| 完形填空 | 20 分 | 逻辑词表 + 30 高频搭配 + 2 套练习 |
| 判断正误 | 10 分 | 六大命题陷阱逐个拆 |
| 选词填空 | 15 分 | 三步法 + 9 类构词法后缀总表 |
| 英译汉选择 | 10 分 | 长难句拆解 + 误译陷阱 |
| 汉译英 | 15 分 | 五大模板句型 + 盲写三步 + 必对关键词 |
| 短文改错 | 20 分 | 十雷区 + 2 套练习 |
| 写作 | 20 分 | 文体模板 + 12 步自评清单 + 2026 AI 话题范文 |

- **全题型模考**：一键按真实卷面连做全套（含 2026 真卷回忆版 61 题）
- **考情总览**：近八年命题规律一页看尽

### 军火库总览（查）—— 一个页面，全站词条
**检索池 5500+ 条**（章节词条 1044 + 全站词典 4477），11 项快捷操作：
即时搜索（中英双语全文）· 六类筛选（核心词/短语/易混/熟词生义/**真题高频**/**高频短语**）· 章节筛选 · 三种排序 · 改错高频过滤 · 星标收藏 · TTS 点读 · 行内展开 · **从结果抽 5 个默写** · 一键复制导出 · 分页浏览

- **真题高频词表 200 词**：带历年真题出现频次（personal 310 次 → broaden 28 次），按频次降序冲刺
- **高频短语表 156 条**：核心动词家族 + 介词搭配，含易错提示（look forward to 后接 doing 等）
- **全词可搜承诺**：全语料 6378 词形逐词审计——系统里出现的每个真实词 100% 可查，变形词（carried→carry / hardest→hard）自动还原

### 复习闭环（复）—— 错了不沉底
- **错题回炉**：答错的题自动进错题池，按 **1 → 3 → 7 → 14 天**间隔重测，连对 2 次毕业出池；选择题原样重测、默写题重拼
- **TTS 发音**：词卡 / 弹层全支持朗读（浏览器原生，离线可用）

### 默写模式（主动召回）
词卡与短语**看中文 → 敲英文 → 逐字母判色**（对绿错红），提示逐字母揭示，错词自动进错题池——把「认识」升级成「写得出」。

### 游戏层
- HUD 段位系统（词士 → 词师 → 词帝）+ 经验条
- 蜿蜒大地图：章节是路上的站点，每大陆终点是 **Boss 关**
- **Boss 血条化测验**：答对扣血、答错回血 + 屏震，满分触发击杀动画
- 通关星级结算 + 经验掉落 + 掉落词卡收藏
- 答题连击、撒花、鼓励气泡——该有的 juice 都有

## 快速开始

**零依赖、零构建、零安装**——纯原生 JavaScript + CSS。

```bash
git clone https://github.com/你的用户名/wordrise.git
cd wordrise
```

然后**直接双击 `index.html`** 即可使用（file:// 协议全功能可用）。

也可以起个本地服务（可选，彻底告别 file:// 的控制台杂音）：

```bash
npx serve .
# 或
python -m http.server 8080
```

- 无后端、无账号、无网络请求——**所有进度存 localStorage，数据 100% 本地**
- 推荐使用 Chrome / Edge 打开；TTS 发音依赖浏览器语音合成

## 设计与架构

- **纯原生 JS**，无框架、无构建、无外部依赖——双击即用，十年后依然能打开
- **数据与渲染分离**：每章一个数据文件，改内容不需要碰逻辑
- **游戏层为注入式插件**（game.js）：通过运行时包装 App 方法实现，与主逻辑解耦
- **设计令牌驱动**：间距 / 字阶 / 色彩 / 动效全部走 CSS 变量，一键换肤成为可能
- **file:// 友好**：所有交互避免页面导航，双击打开与 http 服务体验一致
- **查找链五级兜底**：章节词表 → 不规则还原 → 词形剥离 → 生词库 → 全站词典（含前缀近似），变形词自动还原到词根
